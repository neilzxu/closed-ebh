# Code for [Bringing closure to FDR control: beating the e-Benjamini-Hochberg procedure](https://arxiv.org/abs/2504.11759)

Install necessary packages via:
```{bash}
pip install numpy scipy pandas matplotlib seaborn tqdm
```

Run simulations via
```{bash}
python exp.py
```

Figures for paper and experimental results generated in `figures/` with the closed e-BH results in `figures/simple` and the closed-BY results in `figures/simple-BY`
